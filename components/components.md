# Components

## Proposed Components

| Component | Purpose |
|---|---|
| pH Sensor Module | Detects pH of the water |
| MCP6002 | Signal buffering and conditioning |
| Resistors | Voltage division and gain setting |
| Capacitors | Filtering and supply decoupling |
| LEDs | Visual indication |
| 5V Supply | Powers the circuit |
| Connecting Wires | Electrical connections |

## Status

These components are part of the proposed design.
The circuit has not been physically tested yet.
